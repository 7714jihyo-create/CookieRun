# 🏃‍♂️ Cookie Run Clone Project (프로젝트 제목)

> **유니티(Unity) 엔진을 활용해 제작한 2D 사이드스크롤 러닝 액션 게임 '쿠키런' 모작입니다.**

---

## 🎮 프로젝트 소개
본 프로젝트는 기존 '쿠키런'의 핵심 메커니즘을 유니티 환경에서 구현하며 게임 개발 흐름을 학습하기 위해 제작되었습니다. 
끊임없이 달리는 쿠키를 조작하여 장애물을 피하고 젤리를 획득하며 최고 점수를 기록하는 것을 목표로 합니다.

### 📅 개발 기간
* 2026년 5월 ~ 2026년 X월

### 🛠 개발 환경 및 기술 스택
* **Engine:** Unity 2022.3.62f3 (본인 유니티 버전 입력)
* **Language:** C#
* **Platform:** PC / Android (택일)

---

## ✨ 핵심 구현 기능

* **무한 맵 스크롤링 (Infinite Scrolling):** 쿼드를 활용하여 맵을 끊임없이 생성
* **쿠키 조작 및 애니메이션:** 
  * 점프(Jump) 및 2단 점프 구현.
  * 슬라이드(Slide)를 통한 높이가 낮은 장애물 회피 메커니즘.
  * 각 상태(Run, Jump, Slide)에 따른 애니메이션 전환.

---

## 🕹 조작 방법

| 액션 | 키보드 (PC) | 모바일 터치 |
| :--- | :--- | :--- |
| **점프 (Jump)** | `Space` 또는 `Up Arrow` | 왼쪽 화면 터치 |
| **슬라이드 (Slide)** | `Down Arrow` 또는 `Z` | 오른쪽 화면 터치 |
